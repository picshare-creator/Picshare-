PicShare Android प्रोजेक्ट

यह Android Studio प्रोजेक्ट है। यह अभी APK नहीं है।

APK बनाने के चरण:
1. कंप्यूटर पर Android Studio इंस्टॉल करें।
2. Android Studio में इस ZIP को Extract करके File > Open से PicShareAndroid फ़ोल्डर खोलें।
3. Gradle sync पूरा होने दें; Android SDK Platform 35 डाउनलोड करने को कहे तो डाउनलोड करें।
4. Build > Build Bundle(s) / APK(s) > Build APK(s) चुनें।
5. APK app/build/outputs/apk/debug/app-debug.apk में मिलेगा।
6. APK को अपने Android फोन में भेजकर खोलें और इंस्टॉल करें। केवल अपनी बनाई/विश्वसनीय APK इंस्टॉल करें।

सीमाएँ:
- यह डेमो WebView में चलता है।
- असली ऑनलाइन अकाउंट, सर्वर, क्रॉस-डिवाइस पोस्ट/लाइक और सुरक्षित फोटो स्टोरेज अभी जुड़े नहीं हैं।
- इस वातावरण में APK compile/sign नहीं किया गया है।
